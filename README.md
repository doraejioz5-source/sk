# 전기공학 · AI 프로젝트 포트폴리오

전기공학과 방산 융합 분야를 공부하며 참여하거나 발전시킨 프로젝트를 정리한 포트폴리오입니다. 각 항목은 실제 진행 단계와 확인된 결과를 구분해 작성했습니다.

## 프로젝트

### 1. AI 재검증 Agent — 모델 업데이트 후 오류 분석 지원

**국방 AI 아이디어 경진대회 | 팀장 · 최우수상**

AI 모델을 업데이트한 뒤 기존에 맞게 인식하던 사례가 새롭게 틀리는 문제를 확인하고, 담당자의 재검토를 돕는 대시보드형 도구를 기획·구현했습니다.

- 업데이트 전후의 CSV 시험 결과를 비교해 성능 변화와 새 오류 후보를 확인
- 오류 분석 요약과 재시험 우선순위로 검토 흐름을 지원
- Streamlit 대시보드와 시연 자료를 제작
- 실제 무기체계의 시험 결과나 안전성을 인증하는 도구가 아니라, 검토와 재검증 준비를 돕는 시연 프로젝트

### 2. SeatFlow — 도서관 좌석 관리 서비스

**모두의 창업 1라운드 선정 | 팀장 · 서비스 기획 및 발표**

도서관 좌석 이용과 예약·반납의 불편을 줄이기 위한 좌석 관리 서비스를 기획했습니다.

- 문제 정의, 서비스 구성, 팀 발표를 주도
- ESP32와 좌석 센서, QR/NFC를 활용한 좌석 확인 및 예약 흐름을 설계
- 좌석 점유 확인과 자동 반납을 포함한 앱·시제품 구성을 구상
- 선정 이력은 있으나, 전체 서비스를 완성·상용화한 것으로 표현하지 않습니다.

### 3. PMSM 전류 제어 연구 (E-SynC)

**연구 참여 | 2026.03–12**

PMSM 전류 제어를 주제로 PLECS와 STM32G431RB를 활용해 제어 흐름을 확인하고 모터 구동을 진행했습니다.

- PWM 극성 문제를 확인하고 수정해 실제 모터 구동을 확인
- 시뮬레이션 결과와 임베디드 제어 구현을 연계
- 연구는 진행 중이며, 최종 결과는 연구 완료 후 업데이트할 예정입니다.

### 4. MediRoute AI — 의료기관 연결 지원 아이디어

**SW 창업 아이디어톤 | 사업계획서 및 MVP 설계 단계**

사용자의 설명을 바탕으로 의료기관에 전달할 정보를 정리하는 서비스 아이디어를 구체화하고 MVP 흐름을 설계했습니다.

- 아이디어와 사업계획서 초안을 발전
- 가상 시나리오 중심의 서비스 흐름을 설계
- 임상 검증, 병원 계약, 119 연동은 완료되지 않았으며, 의료 진단이나 응급서비스를 대체하는 서비스로 설명하지 않습니다.

### 5. D-FORGE — AI 기반 초기 R&D 엔지니어링 지원

[GitHub 저장소 보기](https://github.com/doraejioz5-source/d-forge-agentic-engineering)

초기 개발 아이디어를 요구사항, 시스템 구조, 시험·검증, 개발계획으로 정리하는 AI 지원 도구입니다.

- Streamlit 대화형 화면과 프로젝트 상태 관리
- 요구사항·설계·검증·리뷰 등 역할별 에이전트 흐름
- 추적성 점검과 개발계획 생성
- 공개된 저장소의 현재 코드 기준으로 정리했으며, 실제 산업 현장에서 검증된 제품이라고 주장하지 않습니다.

## 전공 및 사용 도구

- **전공 관심:** 전기공학, 임베디드 제어, 모터 제어, 방산 AI 시험·검증
- **사용 경험:** STM32, PLECS, PWM, Streamlit, Python, AI 에이전트 도구
- **프로젝트 경험:** 하드웨어 구동 확인, 데이터 비교, 서비스 기획, 팀 발표

## 작성 원칙

- 아이디어·기획·시연·실제 구현을 구분합니다.
- 선행연구 수치나 가상 데이터를 자체 실험 결과처럼 쓰지 않습니다.
- 확인되지 않은 국내 최초·유일 주장, 임상 효과, 실전 성능을 기재하지 않습니다.
